About NinaTools

Practical online tools, made easier to use.

NinaTools is a free online tools website created to help people complete common digital tasks with clear instructions and straightforward controls. The collection brings useful utilities together in one place, so visitors can find a tool, understand what it does and use it without installing a desktop application.

What you can do with NinaTools

The website focuses on practical tasks that people may need at home, at work or while managing files and information online. Its tools are organised into clear categories:

Image tools

Convert HEIC and PNG images, compress JPG files, and resize images for different uses.

PDF tools

Convert JPG images into PDF documents, merge PDF files and split PDFs by page or page range.

QR code tools

Create QR codes, customise their appearance and download the result as an image.

Internet and text tools

Encode and decode URLs or Base64 text, generate passwords, format JSON, convert timestamps, look up DNS records and check a public IP address.

Currency conversion

Convert between supported currencies using reference exchange-rate data from an external service.

Retirement resources

Find retirement calculators and destination-planning information through our separate project, RetireAtlas.

How the tools work

Many NinaTools utilities are designed to process the information you enter or the files you select directly in your web browser. For those browser-based tasks, the tool code does not upload your selected files to a NinaTools file-processing server.

Some tools need an external service to provide an answer. For example, DNS Lookup uses Google's DNS-over-HTTPS service, the public IP checker uses ipify, and the currency converter retrieves reference rates from the Frankfurter API. Those providers receive the request information needed to return the result and operate under their own terms and privacy practices.

The processing method can therefore differ from one tool to another. Please read the information shown on an individual tool page and avoid entering confidential or sensitive information into any online service unless you understand how it will be handled.

Our principles

  • Clarity: Each tool should explain its purpose and provide controls that are easy to understand.
  • Practical usefulness: We focus on common tasks and features that help visitors complete them.
  • Accessibility across devices: Pages are designed to work on mobile phones, tablets and desktop screens.
  • Privacy awareness: We aim to avoid unnecessary file uploads and explain when an external service is involved.
  • Ongoing improvement: Tools and information may be reviewed and updated as features, browser support and services change.

Updates and feedback

NinaTools is an evolving collection. We review tools and website information and may improve instructions, fix issues or add features as needs become clearer. If you notice a problem or have a suggestion, please contact us through the Contact page.
