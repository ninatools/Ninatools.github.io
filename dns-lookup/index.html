What Is DNS Lookup?

DNS (Domain Name System) translates domain names into information that computers use to find services on the internet. A DNS lookup lets you inspect the records published for a domain.

Common DNS Record Types

  • A: Maps a domain to an IPv4 address.
  • AAAA: Maps a domain to an IPv6 address.
  • MX: Lists mail servers for a domain.
  • NS: Identifies authoritative name servers.
  • TXT: Stores text data, often used for verification and email security.
  • CNAME: Points one name to another canonical name.

Is this DNS Lookup tool free?

Yes. NinaTools provides this interface for free. DNS queries are sent to Google's public DNS-over-HTTPS service, which is subject to its own availability and privacy practices.

Why might no records appear?

A domain may not have the selected record type, the response may be cached or unavailable, or the DNS service may return an error. Try another record type or check the domain spelling.

Does a DNS lookup show every DNS record?

No. Results depend on the selected query, the public resolver's response, and the records it returns. This tool does not guarantee a complete authoritative zone listing.
