How to create a QR code

  1. Enter the website address or text you want the QR code to contain.
  2. Choose a foreground colour and a background colour, or select one of the ready-made colour combinations.
  3. Select Generate QR Code and check the preview.
  4. Scan the preview with a phone camera or QR scanner to confirm it opens the correct content.
  5. Download the image as PNG or JPG. Keep the downloaded file so you can test it again before printing or sharing.

Tips for making a QR code easier to scan

  • Use strong contrast. A dark code on a light background is usually easier for cameras to read than two similar colours.
  • Keep the clear border. Leave a quiet margin around the QR pattern when placing it in a design; do not crop tightly around the squares.
  • Avoid stretching. Keep the code square and do not distort its proportions when resizing it.
  • Test at the final size. Scan a printed sample or the image displayed at the size people will actually see.
  • Check the destination. Make sure the URL is correct and that the linked page is available before distributing the code.

What can a QR code contain?

This generator can encode text or a website URL. When someone scans the code, their device reads the encoded content. If the content is a web address, the scanner may offer to open that address. A QR code does not make a website trustworthy, so people should check unfamiliar links before opening them.

Privacy and technical note

The QR pattern is created in your browser. The text or website address you enter is used by the page's QR code library to create the preview; this page does not send that entered content to NinaTools' server. The QR code library itself is downloaded from a third-party content delivery network, so your browser makes a request to that provider to load the software.

Frequently asked questions

Will a QR code expire?

A QR code image does not normally expire by itself. However, a website address encoded in it may stop working if the page is removed, the domain changes or the destination is unavailable.

Can I change the colours?

Yes. Choose the code and background colours or use a preset. Always test the finished code after changing its colours because low contrast can make scanning difficult.

Should I download PNG or JPG?

PNG is generally a good choice for a crisp QR graphic. JPG can be convenient when a workflow specifically requires a JPEG image. Whichever format you choose, scan the downloaded file before sharing it.

Why does my phone not scan the code?

Check that the code is fully visible, in focus, not distorted and has enough contrast and clear space around it. Try generating it again and scanning the new download.
